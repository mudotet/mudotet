## 🛰️ How I like to build

```text
User problem
     │
     ▼
Clear requirements
     │
     ▼
API contract
     │
     ▼
Business logic
     │
     ├──────────► Database
     │
     ├──────────► Cache
     │
     └──────────► AI service
     │
     ▼
Test, debug and improve
```

My current goal is not to create the most complicated architecture.

It is to build systems that are:

```text
✓ understandable
✓ maintainable
✓ secure
✓ testable
✓ useful
```
